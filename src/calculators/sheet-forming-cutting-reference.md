# فرم‌دهی و برش ورق — مرجع محاسبات مهندسی
# Sheet Metal Forming & Cutting — Engineering Calculation Reference

مرجع فرمول‌ها، ضرایب و مثال‌های حل‌شده برای افزودن ماژول «فرم‌دهی و برش» به نرم‌افزار ماشین‌حساب مهندسی.
Companion to `sheetForming.js`. Same unit system and architecture as the bulk-forming module.

**دامنه پوشش / Scope:** برشکاری مکانیکی (برش، بلانکینگ، پانچینگ) + خم‌کاری + کشش عمیق.

---

## 0. تفاوت بنیادی با فرم‌دهی حجمی — How sheet differs from bulk

این تفاوت صرفاً اصطلاحی نیست؛ **فیزیک و معیار خرابی عوض می‌شود** و به همین دلیل ماژول جداست.

| | فرم‌دهی حجمی / Bulk | فرم‌دهی ورق / Sheet |
|---|---|---|
| نسبت سطح به حجم | کم | زیاد |
| ضخامت | متغیر طراحی فعال | تقریباً ثابت — تغییرش **عیب** است |
| حالت تنش | سه‌محوری فشاری | **تنش صفحه‌ای** (σ₃ ≈ 0) |
| تنش غالب | فشاری | کششی |
| معیار خرابی | ترک، جریان ناقص قالب | **گلویی‌شدن، پارگی، چروکیدگی، برگشت فنری** |
| نقش اصطکاک | مقاومت مستقیم | کنترل جریان مواد از زیر ورق‌گیر |
| پارامتر کلیدی ماده | K, n | K, **n**, **r̄** (ناهمسانگردی) |

نتیجه عملی: در فرم‌دهی ورق، `n` (توان کارسختی) و `r̄` (ناهمسانگردی نرمال) اهمیت بیشتری از استحکام مطلق دارند. یک فولاد ضعیف‌تر با `n` بالاتر بهتر فرم می‌گیرد.

## 1. مبانی ورق — Sheet Fundamentals

### 1.1 تنش صفحه‌ای

```
σ3 ≈ 0        (عمود بر سطح ورق)
ε1 + ε2 + ε3 = 0     ⇒     ε3 = −(ε1 + ε2)      ← نازک‌شدگی
```

نازک‌شدگی (thinning) پیامد اجتناب‌ناپذیر کشیدگی است. معیار عملی: نازک‌شدگی موضعی بیش از **۲۰–۲۵٪** به گلویی‌شدن ختم می‌شود.

```
t_final = t0 · exp(ε3) = t0 · exp(−(ε1 + ε2))
thinning% = (1 − t_final/t0) × 100
```

### 1.2 ناهمسانگردی — Anisotropy (r-value)

ورق نورد شده ذاتاً ناهمسانگرد است. نسبت لنکفورد:

```
r = ε_w / ε_t = ln(w0/wf) / ln(t0/tf)
```

عملاً `t` را نمی‌شود دقیق اندازه گرفت، پس از ثبات حجم:

```
r = ln(w0/wf) / ln(L_f·w_f / (L0·w0))
```

**ناهمسانگردی نرمال (میانگین):**

```
r̄ = (r0 + 2·r45 + r90) / 4
```

**ناهمسانگردی صفحه‌ای (عامل گوش‌دار شدن):**

```
Δr = (r0 − 2·r45 + r90) / 2
```

| کمیت | معنی | اثر |
|---|---|---|
| `r̄ > 1` | ورق در برابر نازک‌شدن مقاوم است | **کشش عمیق بهتر** — LDR بالاتر |
| `r̄ < 1` | ورق ترجیح می‌دهد نازک شود | کشش عمیق ضعیف، اما stretch forming بهتر |
| `Δr ≠ 0` | خواص در جهات مختلف فرق دارد | **گوش‌دار شدن** (earing) لبه فنجان |

هدف طراحی: `r̄` بالا، `Δr ≈ 0`.

**رابطه با حد کشش (LDR):**

```
LDR_theoretical ≈ exp(η · r̄^0.5 ...)     ← فرم‌های تجربی متعدد
تقریب عملی:  LDR ≈ 2.0 + 0.5·(r̄ − 1)     برای 0.5 < r̄ < 2.5
```

فولاد کم‌کربن `r̄ ≈ 1.4–1.8` ⇒ LDR ≈ 2.2؛ آلومینیوم `r̄ ≈ 0.6–0.8` ⇒ LDR ≈ 1.9. تیتانیوم `r̄ ≈ 4–6` ⇒ کشش‌پذیری استثنایی.

### 1.3 کشیدگی یکنواخت و n

در کشش تک‌محوری، ناپایداری (گلویی‌شدن) دقیقاً وقتی شروع می‌شود که:

```
ε_uniform = n
```

پس `n` مستقیماً حد کشیدگی قابل استفاده است. فولاد کم‌کربن `n ≈ 0.22–0.26`، آلومینیوم `n ≈ 0.20–0.25`، برنج `n ≈ 0.49`.

### 1.4 استحکام برشی — Shear strength

پایه‌ی همه‌ی محاسبات نیروی برش:

```
S ≈ 0.7 · UTS         (تقریب عمومی، فولاد و اکثر فلزات)
S ≈ 0.6 – 0.65 · UTS  (آلومینیوم و آلیاژهای نرم)
S ≈ 0.75 – 0.80 · UTS (فولادهای پرکربن و زنگ‌نزن)
```

از معیار von Mises مقدار نظری `S = UTS/√3 = 0.577·UTS` می‌آید، اما در برش واقعی به‌خاطر تغییر شکل نامتقارن و اصطکاک، عدد اندازه‌گیری‌شده بالاتر است. **از مقدار جدول ماده استفاده کنید، نه از 0.577.**

## 2. برشکاری — Shearing / Blanking / Punching

### 2.1 مکانیزم و مناطق لبه برش

برش در سه مرحله رخ می‌دهد و لبه‌ی حاصل چهار ناحیه دارد:

```
1. Rollover  (گردشدگی لبه)      ~10–20٪ ضخامت
2. Burnish   (سطح براق، برش خالص) ~30–40٪  ← ناحیه‌ی کیفی
3. Fracture  (شکست، زبر و مخروطی) ~40–50٪
4. Burr      (پلیسه)              تابع کندی ابزار
```

**نفوذ تا شکست** (`pt`, penetration fraction) — پارامتر کلیدی محاسبه انرژی:

| ماده | Material | pt |
|---|---|---|
| فولاد نرم / آلومینیوم نرم | Soft, ductile | 0.50 – 0.60 |
| فولاد نیمه‌سخت | Half-hard steel | 0.35 – 0.45 |
| فولاد سخت / فنری | Hard / spring steel | 0.20 – 0.30 |

### 2.2 لقی — Clearance

مهم‌ترین پارامتر کیفیت در برشکاری. لقی **یک‌طرفه** `c`:

```
c = Ac · t
```

`Ac` = ضریب لقی، تابع ماده:

| ماده | Material | Ac |
|---|---|---|
| آلومینیوم 1100، 5052 | Al 1100, 5052 | 0.045 |
| آلومینیوم 2024-T، 6061-T | Al 2024-T, 6061-T | 0.060 |
| فولاد نورد سرد، نیمه‌سخت | CR steel, half hard | 0.075 |
| فولاد زنگ‌نزن، نیمه‌سخت | Stainless, half hard | 0.075 |
| فولاد نرم آنیل | Soft annealed steel | 0.060 |
| مس و برنج | Copper, brass | 0.050 |

محدوده عملی کلی: **۲ تا ۱۰ درصد ضخامت** به‌ازای هر طرف.

**اثر لقی نادرست:**

| حالت | نتیجه |
|---|---|
| لقی خیلی کم | برش دوباره، پلیسه ثانویه، نیروی بالا، سایش شدید سنبه |
| لقی بهینه | ترک بالا و پایین به هم می‌رسند — لبه تمیز، نیروی کمینه |
| لقی خیلی زیاد | گردشدگی زیاد، پلیسه بلند، اعوجاج، ابعاد خارج از تلرانس |

### 2.3 ابعاد سنبه و ماتریس — Punch and die sizing

اینجا **جهت اعمال لقی** به نوع عملیات بستگی دارد و رایج‌ترین خطای طراحی قالب است:

**بلانکینگ (Blanking)** — قطعه‌ی جدا‌شده محصول است ⇒ ماتریس ابعاد را تعیین می‌کند:

```
D_die   = D_blank
D_punch = D_blank − 2c
```

**پانچینگ / سوراخ‌کاری (Punching)** — سوراخ محصول است ⇒ سنبه ابعاد را تعیین می‌کند:

```
D_punch = D_hole
D_die   = D_hole + 2c
```

**زاویه آزاد ماتریس (angular clearance / die relief):** `0.25° – 1.5°` در هر طرف، زیر زمین برش (land) به ارتفاع `3–10 mm`، برای خروج آزاد قطعه.

### 2.4 نیروی برش — Cutting force

```
F = S · t · L
```

- `S` = استحکام برشی (MPa)
- `t` = ضخامت ورق (mm)
- `L` = **محیط کل خط برش** (mm) — نه سطح!

برای دایره: `L = π·D`. برای مستطیل: `L = 2(a+b)`. برای شکل پیچیده: مجموع طول تمام کانتورها، از جمله سوراخ‌های داخلی.

**فرم جایگزین با UTS:**  `F = 0.7 · UTS · t · L`

### 2.5 کاهش نیرو با پله/شیب — Force reduction by shear (bevel)

با شیب دادن به سطح سنبه یا ماتریس، برش تدریجی می‌شود و پیک نیرو می‌شکند (انرژی کل ثابت می‌ماند):

```
F_sheared ≈ F · t / (t + h_shear)
```

`h_shear` = عمق شیب. با `h_shear = t` نیرو تقریباً **نصف** می‌شود. با `h_shear = 2t` به ~یک‌سوم.

نکته: شیب روی **سنبه** ⇒ قطعه‌ی جدا شده تخت می‌ماند (برای پانچینگ). شیب روی **ماتریس** ⇒ بلانک تخت می‌ماند (برای بلانکینگ). اشتباه کردن این دو، قطعه را کاسه‌ای می‌کند.

### 2.6 نیروی جداکننده — Stripping force

نیروی لازم برای جدا کردن ورق از سنبه در برگشت:

```
F_strip = k_s · F_cut         ,  k_s = 0.02 – 0.20  (معمول 0.05 – 0.10)
```

`k_s` بزرگ‌تر برای: ورق نازک، محیط برش زیاد نسبت به سطح، سنبه‌های متعدد نزدیک هم، لقی کم.

**نیروی کل پرس:**  `F_press = F_cut + F_strip`

### 2.7 انرژی و انتخاب پرس — Energy

```
W = F_max · t · pt              (J اگر F به N و t به m)
W [J] = F[N] · t[mm] · pt / 1000
```

انرژی، نه فقط تناژ، معیار انتخاب پرس‌های ضربه‌ای و اکسنتریک است.

**تناژ پرس پیشنهادی:**  `F_press_rated ≥ 1.2 × (F_cut + F_strip)`

### 2.8 بررسی مقاومت سنبه — Punch strength checks

دو خرابی محتمل، هر دو باید بررسی شوند:

**۱. تنش فشاری سنبه:**

```
σ_punch = F / A_punch = 4F / (π·d²)      ≤ σ_allow
σ_allow ≈ 1500 – 2500 MPa  (فولاد ابزار سخت‌شده)
```

⇒ **حداقل قطر سوراخ:**  `d_min = √(4·S·t·... )`، یا قاعده عملی:

```
d_min ≈ k · t     ,   k = 1.0 (فولاد نرم) ... 2.0 (فولاد سخت / زنگ‌نزن)
```

**۲. کمانش سنبه (سنبه‌های بلند و باریک) — Euler:**

```
L_max = √( π² · E · I / (4 · F) )         (یک سر گیردار، یک سر آزاد)
I = π·d⁴/64                                (مقطع دایره)
```

با ضریب اطمینان ۲–۳. سنبه‌های بلندتر باید داخل **راهنمای سنبه** (punch guide / stripper plate) بسته شوند.

### 2.9 برش با گیوتین — Guillotine / rake-angle shearing

تیغه‌ی زاویه‌دار برش را تدریجی می‌کند:

```
F = S · t² / (2 · tan φ)
```

`φ` = زاویه تیغه (rake angle)، معمولاً `0.5° – 3°`. توجه: در این فرمول نیرو به **طول برش وابسته نیست** — فقط به ضخامت و زاویه.

### 2.10 چیدمان نوار و بازده مواد — Strip layout & material utilization

```
گام (pitch):        p = W_part + w_bridge
عرض نوار:           W_strip = H_part + 2·w_edge
بازده مواد:         η = (n · A_part) / (p · W_strip)
```

**عرض پل ضایعات (`w_bridge`) و لبه (`w_edge`)** — قواعد عملی:

| ضخامت ورق | w_bridge (mm) | w_edge (mm) |
|---|---|---|
| t < 1 | 1.0 | 1.5 |
| 1 ≤ t < 2 | 1.0 × t | 1.5 × t |
| 2 ≤ t < 4 | 1.2 × t | 1.5 × t |
| t ≥ 4 | 1.5 × t | 2.0 × t |

حداقل مطلق: **1 mm**. برای قطعات باریک و بلند، پل را بزرگ‌تر بگیرید تا نوار در حین تغذیه پاره نشود.

**چیدمان مورب یا دو‌ردیفه** (staggered / double-row) بازده را برای اشکال دایره‌ای تا ۱۰–۱۵٪ بالا می‌برد؛ در قالب پیشرو ارزش سرمایه‌گذاری دارد.

### 2.11 عملیات مرتبط

| عملیات | Operation | تعریف |
|---|---|---|
| بلانکینگ | Blanking | قطعه‌ی جداشده محصول است |
| پانچینگ/سوراخ‌کاری | Punching / Piercing | سوراخ محصول است، جداشده ضایعات |
| شیارزنی | Notching | برداشتن ماده از لبه |
| جداسازی | Parting | برش نوار به دو قطعه، بدون ضایعات میانی |
| نیم‌برش | Lancing | برش بدون جدا کردن کامل (برای زبانه) |
| پیرایش | Trimming | حذف ماده اضافی پس از فرم‌دهی |
| تراش‌برداری | Shaving | برش مجدد ۱۰٪ برای لبه صاف و دقیق |
| نیبلینگ | Nibbling | برش کانتور با ضربات متوالی سنبه کوچک |

## 3. خم‌کاری — Bending

### 3.1 هندسه خم و تار خنثی

در خم، سطح خارجی کشیده و داخلی فشرده می‌شود؛ بین آن‌ها **تار خنثی** قرار دارد که به سمت داخل جابه‌جا می‌شود.

**ضریب K (K-factor)** — موقعیت نسبی تار خنثی:

```
K = فاصله تار خنثی از سطح داخلی / t
```

| R/t | K معمول |
|---|---|
| < 0.5 | 0.30 |
| 0.5 – 1.5 | 0.33 |
| 1.5 – 3 | 0.40 |
| > 3 | 0.45 – 0.50 |

قاعده ساده‌شده (Groover): `K = 0.33` اگر `R < 2t`، و `K = 0.50` اگر `R ≥ 2t`.

### 3.2 طول خم و طول گسترده — Bend allowance & flat pattern

```
BA = (α_deg · π/180) · (R + K·t)             ← طول قوس تار خنثی
```

**طول گسترده ورق:**

```
L_flat = Σ(طول قسمت‌های تخت) + Σ(BA)
```

**فرم جایگزین با کسر خم (Bend Deduction)** — رایج در نرم‌افزارهای CAD:

```
OSSB = (R + t) · tan(α/2)                    ← Outside SetBack
BD   = 2·OSSB − BA
L_flat = Σ(طول لبه‌های بیرونی) − Σ(BD)
```

هر دو روش یک جواب می‌دهند؛ `BD` وقتی راحت‌تر است که ابعاد نقشه بیرون-تا-بیرون باشد.

### 3.3 نیروی خم — Bending force

```
F = Kbf · UTS · w · t² / D
```

- `w` = عرض خم (طول خط خم، mm)
- `D` = دهانه ماتریس (die opening, mm)
- `Kbf` = **1.33** برای قالب V، **0.33** برای قالب wiping (لبه‌خم‌کن)

**دهانه ماتریس توصیه‌شده:**

```
D = 6t   تا  12t        (معمول: 8t)
```

`D` کوچک‌تر ⇒ نیروی بیشتر، شعاع خم کوچک‌تر، برگشت فنری کمتر. `D` بزرگ‌تر ⇒ نیروی کمتر ولی برگشت فنری بیشتر و شعاع بزرگ‌تر.

**شعاع خم در هوا (air bending):** شعاع نتیجه‌ی دهانه است، نه سنبه:

```
R_air ≈ 0.16 · D          (تقریب برای فولاد نرم)
```

**بستن کامل / کوبش (bottoming & coining):** نیرو ۳ تا ۵ برابر (bottoming) یا ۵ تا ۱۰ برابر (coining) خم در هوا می‌شود، ولی برگشت فنری تقریباً حذف می‌شود.

### 3.4 برگشت فنری — Springback

بازیابی الاستیک پس از باز شدن قالب. مهم‌ترین مسئله عملی خم‌کاری.

**رابطه شعاع (Kalpakjian):**

```
Ri/Rf = 4·(Ri·Y/(E·t))³ − 3·(Ri·Y/(E·t)) + 1
```

- `Ri` = شعاع داخلی زیر بار، `Rf` = شعاع پس از رهاسازی (`Rf > Ri`)
- `Y` = تنش تسلیم (MPa)، `E` = مدول یانگ (MPa)

**ضریب برگشت فنری:**

```
Ks = αf / αi = (2Ri/t + 1) / (2Rf/t + 1)
```

**زاویه‌ی جبران (overbend) لازم:**

```
α_die = α_target / Ks
```

**عوامل مؤثر:**

| عامل | افزایش آن ⇒ برگشت فنری |
|---|---|
| تنش تسلیم Y | ↑ بیشتر |
| مدول یانگ E | ↓ کمتر |
| نسبت R/t | ↑ بیشتر (بسیار حساس) |
| ضخامت t | ↓ کمتر |

به همین دلیل فولاد پراستحکام (AHSS) و آلومینیوم (E پایین) برگشت فنری شدید دارند و بدون جبران قابل تولید نیستند.

**روش‌های کنترل:** اضافه‌خم (overbending)، کوبش کف (bottoming/coining)، خم کششی (stretch bending با کشش محوری ۲٪)، شیار در تار خنثی، جبران هندسی قالب از روی شبیه‌سازی.

### 3.5 حداقل شعاع خم — Minimum bend radius

```
R_min = t · (50/AR − 1)
```

`AR` = درصد کاهش سطح در آزمون کشش (tensile reduction of area, %).

**جدول عملی (آنیل‌شده، دمای اتاق):**

| ماده | Material | R_min / t |
|---|---|---|
| آلومینیوم نرم 1100-O | Soft aluminum | 0 |
| مس آنیل | Annealed copper | 0 |
| برنج نرم | Soft brass | 0 |
| فولاد کم‌کربن 1010 | Low-C steel | 0.5 |
| فولاد زنگ‌نزن 304 آنیل | Stainless 304 ann. | 0.5 |
| آلومینیوم 5052-O | Al 5052-O | 0.5 |
| تیتانیوم خالص | Titanium, pure | 0.7 |
| آلومینیوم 2024-T4 | Al 2024-T4 | 3.0 |
| آلومینیوم 6061-T6 | Al 6061-T6 | 3.0 |
| فولاد 4140 آنیل | 4140 annealed | 2.0 |
| Ti-6Al-4V | Ti-6Al-4V | 4.0 |

**جهت خم نسبت به جهت نورد:** خم عمود بر جهت نورد بهتر است. برای خم موازی با جهت نورد، `R_min` را **۱.۵ تا ۲ برابر** بگیرید. برای خم دوطرفه (مثلاً فلنج L)، هر دو خم را ۴۵° نسبت به جهت نورد بچینید.

### 3.6 قواعد طراحی خم

```
حداقل طول لبه:      L_flange ≥ 2.5·t + R      (وگرنه لبه در ماتریس نمی‌نشیند)
فاصله سوراخ تا خم:  d_hole ≥ 2.5·t + R        (وگرنه سوراخ بیضی می‌شود)
فاصله بین دو خم:    ≥ 3·t
پهن‌شدگی لبه:        در انتهای خط خم، ورق کمی پهن می‌شود — در تلرانس لحاظ کنید
```

## 4. کشش عمیق — Deep Drawing

### 4.1 قطر بلانک — Blank diameter

از برابری سطح (فرض ضخامت ثابت). برای فنجان استوانه‌ای بدون فلنج، با `d` = قطر متوسط فنجان، `h` = ارتفاع، `r` = شعاع گوشه کف:

```
r کوچک (d/r > 20):        Db = √(d² + 4·d·h)
15 < d/r ≤ 20:            Db = √(d² + 4·d·h − 0.5·r)
10 < d/r ≤ 15:            Db = √(d² + 4·d·h − r)
d/r ≤ 10:                 Db = √((d − 2r)² + 4·d·(h − r) + 2π·r·(d − 0.7·r))
```

به قطر محاسبه‌شده **۳ تا ۵ درصد** اضافه کنید برای پیرایش لبه (گوش‌دار شدن).

### 4.2 معیارهای امکان‌پذیری — Feasibility criteria

سه قید که **همزمان** باید برقرار باشند:

```
۱. نسبت کشش:      DR = Db / Dp ≤ 2.0
۲. نسبت کاهش:     r  = (Db − Dp)/Db ≤ 0.50
۳. نسبت ضخامت:    t / Db ≥ 0.01   (یعنی ≥ ۱٪)
```

اگر `t/Db < 1%`، نیروی ورق‌گیر برای جلوگیری از چروکیدگی حیاتی می‌شود و پنجره‌ی فرآیند بسیار باریک است.

اگر `DR > 2.0` ⇒ **کشش چندمرحله‌ای** لازم است (بخش ۴.۶).

**حد کشش (LDR)** = بیشترین `DR` که بدون پارگی ممکن است؛ تابع `r̄`:

| ماده | r̄ | LDR عملی |
|---|---|---|
| فولاد کم‌کربن کشش عمیق (DDQ) | 1.6 – 2.0 | 2.1 – 2.3 |
| فولاد کم‌کربن معمولی | 1.2 – 1.5 | 2.0 – 2.1 |
| فولاد زنگ‌نزن 304 | 0.9 – 1.1 | 1.9 – 2.0 |
| آلومینیوم و آلیاژها | 0.6 – 0.8 | 1.8 – 2.0 |
| برنج 70-30 | 0.8 – 1.0 | 2.0 – 2.1 |
| تیتانیوم خالص | 4 – 6 | 2.4 – 3.0 |

### 4.3 نیروی کشش — Drawing force

```
F_draw = π · Dp · t · UTS · (Db/Dp − 0.7)
```

جمله‌ی `−0.7` تصحیح تجربی برای اصطکاک و خمش/بازخمش روی شعاع ماتریس است. نیرو در حدود **یک‌سوم ابتدایی کورس** به حداکثر می‌رسد، نه در انتها.

### 4.4 نیروی ورق‌گیر — Blankholder force

بدون ورق‌گیر، فلنج تحت تنش محیطی فشاری **چروک** می‌شود. با ورق‌گیر بیش از حد، جریان مواد بسته می‌شود و کف **پاره** می‌شود. پنجره‌ی فرآیند بین این دو است.

```
F_hold = 0.015 · Y · π · [ Db² − (Dp + 2.2·t + 2·Rd)² ]
```

- `Y` = تنش تسلیم (MPa)
- `Rd` = شعاع گوشه ماتریس (mm)

قاعده عملی جایگزین: `F_hold ≈ 0.3 × F_draw` تا `0.4 × F_draw`.

**تناژ کل پرس:**  `F_total = F_draw + F_hold`، و ظرفیت پرس `≥ 1.2 × F_total`.

### 4.5 شعاع‌ها و لقی — Radii and clearance

```
شعاع ماتریس:   Rd = 4t  تا  10t        (معمول 6t–8t)
شعاع سنبه:     Rp = 3t  تا  10t        (نباید از Rd کوچک‌تر باشد)
لقی کشش:       c  = 1.1·t  تا  1.15·t   (به‌ازای هر طرف)
```

`Rd` خیلی کوچک ⇒ پارگی روی شعاع. `Rd` خیلی بزرگ ⇒ ناحیه‌ی بدون تکیه‌گاه زیاد ⇒ چروکیدگی.

**اتوکشی (Ironing):** اگر `c < t`، دیواره‌ی فنجان نازک و صاف می‌شود (مثل قوطی نوشابه). نیروی جداگانه‌ای می‌خواهد:

```
F_iron = π · d_mean · t_f · UTS · ln(t0/t_f)
```

### 4.6 کشش مجدد — Redrawing

وقتی `DR > 2.0`، در چند مرحله:

```
مرحله ۱:  DR1 = 1.6 – 2.0    (کاهش 40–50٪)
مرحله ۲:  DR2 = 1.2 – 1.4    (کاهش 20–30٪)
مرحله ۳+: DR3 = 1.15 – 1.25  (کاهش 15–20٪)
```

هر مرحله محدودتر از قبلی است چون ماده کارسخت شده. اگر کرنش تجمعی از ظرفیت شکل‌پذیری بگذرد، **آنیل میانی** لازم است.

**کشش معکوس (reverse redrawing):** فنجان از سمت مخالف کشیده می‌شود؛ چون جهت خمش برعکس می‌شود، کارسختی کمتر انباشته می‌شود و کاهش بیشتری در هر مرحله ممکن است.

### 4.7 عیوب کشش عمیق — Defects

| عیب | Defect | علت | راه‌حل |
|---|---|---|---|
| چروکیدگی فلنج | Flange wrinkling | نیروی ورق‌گیر کم، t/Db کوچک | افزایش F_hold، draw bead |
| چروکیدگی دیواره | Wall wrinkling | لقی زیاد، Rd بزرگ | کاهش لقی |
| پارگی | Tearing / fracture | F_hold زیاد، Rd کوچک، DR بزرگ | کاهش F_hold، افزایش Rd، مرحله‌ای کردن |
| گوش‌دار شدن | Earing | ناهمسانگردی صفحه‌ای Δr | پیرایش لبه؛ انتخاب ورق با Δr کم |
| خط‌افتادگی سطح | Surface scratching | روانکاری ضعیف، سطح قالب زبر | پولیش قالب، روانکار مناسب |
| خطوط لودرز | Lüders bands / stretcher strains | فولاد کم‌کربن با نقطه تسلیم مشخص | نورد پوسته‌ای (skin pass) قبل از فرم |

**رد کششی (Draw bead):** برجستگی روی ورق‌گیر که با ایجاد خمش/بازخمش، مقاومت جریان موضعی ایجاد می‌کند — ابزار دقیق‌تری از افزایش کلی `F_hold` برای کنترل جریان در قطعات نامتقارن.

### 4.8 کار و انرژی

```
W ≈ F_draw_avg · h        ,   F_draw_avg ≈ 0.7 · F_draw_max
W [J] = F[N] · h[mm] / 1000
```

## 6. مثال‌های حل‌شده — Worked Examples

این‌ها به‌عنوان تست پذیرش در `sheetForming.test.js` کدگذاری شده‌اند.

### مثال ۱ — بلانکینگ دیسک

دیسک `⌀75 mm` از ورق فولاد نورد سرد نیمه‌سخت، `t = 3.2 mm`, `UTS = 400 MPa`, `Ac = 0.075`.

```
c        = 0.075 × 3.2 = 0.24 mm
D_die    = 75.00 mm            (بلانکینگ ⇒ ماتریس تعیین‌کننده)
D_punch  = 75 − 2(0.24) = 74.52 mm
L        = π × 75 = 235.62 mm
S        = 0.7 × 400 = 280 MPa
F_cut    = 280 × 3.2 × 235.62 = 211,120 N ≈ 211.1 kN
F_strip  = 0.10 × 211.1 = 21.1 kN
F_press  = 232.2 kN   ⇒  ظرفیت پرس ≥ 279 kN (≈ 28 تن)
W        = 211,120 × 3.2 × 0.4 / 1000 = 270.2 J
```

با شیب `h_shear = t = 3.2 mm` روی ماتریس:  `F = 211.1 × 3.2/6.4 = 105.6 kN` — نصف.

### مثال ۲ — پانچینگ سوراخ (توجه به معکوس شدن لقی)

سوراخ `⌀20 mm` در همان ورق:

```
D_punch = 20.00 mm             (پانچینگ ⇒ سنبه تعیین‌کننده)
D_die   = 20 + 2(0.24) = 20.48 mm
L       = π × 20 = 62.83 mm
F_cut   = 280 × 3.2 × 62.83 = 56,300 N ≈ 56.3 kN
σ_punch = 4 × 56,300 / (π × 20²) = 179.2 MPa   ✓ (بسیار زیر 1500 MPa)
d_min   ≈ 1.0 × 3.2 = 3.2 mm   ⇒ سوراخ 20 mm بی‌خطر
```

### مثال ۳ — خم‌کاری V

خم 90°، `w = 40 mm`, `t = 4 mm`, `R = 6 mm`, دهانه ماتریس `D = 32 mm` (8t), `UTS = 400 MPa`, `Y = 250 MPa`, `E = 207 GPa`.

```
2t = 8 > R = 6   ⇒  Kba = 0.33
BA   = (90×π/180) × (6 + 0.33×4) = 1.5708 × 7.32 = 11.498 mm
OSSB = (6 + 4) × tan(45°) = 10.0 mm
BD   = 2(10.0) − 11.498 = 8.502 mm
F    = 1.33 × 400 × 40 × 4² / 32 = 1.33 × 400 × 40 × 0.5 = 10,640 N ≈ 10.6 kN

برگشت فنری:
  Ri·Y/(E·t) = 6 × 250 / (207,000 × 4) = 0.0018116
  Ri/Rf = 4(0.0018116)³ − 3(0.0018116) + 1 = 0.9945652
  Rf    = 6 / 0.9945652 = 6.0328 mm
  Ks    = (2×6/4 + 1)/(2×6.0328/4 + 1) = 4.0/4.0164 = 0.99592
  زاویه قالب لازم = 90 / 0.99592 = 90.37°   ⇒ اضافه‌خم 0.37°
```

### مثال ۴ — کشش عمیق فنجان

فنجان `Dp = 60 mm`, ارتفاع `h = 26.67 mm`, `t = 2 mm`, `Rd = 8 mm`, `UTS = 400 MPa`, `Y = 250 MPa`.

```
Db      = √(60² + 4×60×26.67) = √(3600 + 6400) = √10000 = 100 mm
DR      = 100/60 = 1.667      ≤ 2.0  ✓
r       = (100−60)/100 = 0.40 ≤ 0.50 ✓
t/Db    = 2/100 = 0.02 = 2٪    ≥ 1٪  ✓
F_draw  = π × 60 × 2 × 400 × (1.667 − 0.7) = 150,796 × 0.9667 = 145,770 N ≈ 145.8 kN
F_hold  = 0.015 × 250 × π × [100² − (60 + 4.4 + 16)²]
        = 11.781 × [10000 − 6464.2] = 41,657 N ≈ 41.7 kN
F_total = 187.4 kN  ⇒ ظرفیت پرس ≥ 225 kN (≈ 23 تن)
لقی      = 1.1 × 2 = 2.2 mm در هر طرف
W       ≈ 0.7 × 145,770 × 26.67/1000 = 2721 J
```

### مثال ۵ — چیدمان نوار

بلانک `⌀75 mm` از مثال ۱، `t = 3.2 mm`:

```
w_bridge = 1.2 × 3.2 = 3.84 mm    (چون 2 ≤ t < 4)
w_edge   = 1.5 × 3.2 = 4.80 mm
pitch    = 75 + 3.84 = 78.84 mm
W_strip  = 75 + 2(4.80) = 84.60 mm
A_part   = π × 75²/4 = 4417.9 mm²
η        = 4417.9 / (78.84 × 84.60) = 4417.9 / 6669.9 = 0.6624  ⇒ 66.2٪
```

با چیدمان دو‌ردیفه‌ی مورب این عدد به ~۷۵٪ می‌رسد — برای تولید انبوه، اختلاف قابل توجهی در هزینه مواد است.

| فرآیند | شرط | پیام |
|---|---|---|
| برش | `c/t < 0.02` یا `> 0.10` | لقی خارج از محدوده عملی |
| برش | نوع عملیات نامشخص | جهت اعمال لقی (سنبه یا ماتریس) باید مشخص شود |
| برش | `d_hole < t` | سوراخ کوچک‌تر از ضخامت — خطر شکست سنبه |
| برش | `σ_punch > 1500 MPa` | تنش سنبه بیش از حد مجاز |
| برش | `L_punch > L_buckling` | خطر کمانش سنبه — راهنما لازم است |
| خم | `R < R_min` | ترک سطح خارجی خم |
| خم | `D < 6t` یا `> 12t` | دهانه ماتریس خارج از محدوده توصیه‌شده |
| خم | `L_flange < 2.5t + R` | لبه کوتاه‌تر از حد؛ در ماتریس نمی‌نشیند |

| کشش | `DR > 2.0` | یک مرحله کافی نیست — کشش چندمرحله‌ای |

| کشش | `Rd < 4t` | خطر پارگی روی شعاع ماتریس |
| کشش | `c < t` | اتوکشی (ironing) رخ می‌دهد — نیروی اضافی |
| همه | `t ≤ 0`, `UTS ≤ 0` | ورودی نامعتبر |

## 8. یکاها و پیاده‌سازی — Units & implementation

همان سیستم **mm–N–MPa** ماژول فرم‌دهی حجمی:

```
طول mm | سطح mm² | تنش MPa | نیرو N | انرژی: N·mm/1000 = J
زاویه: درجه در لایه API، رادیان در محاسبات داخلی
```

تله‌های شایع در این ماژول:

- **جهت لقی**: بلانکینگ ⇒ روی سنبه اعمال می‌شود؛ پانچینگ ⇒ روی ماتریس. معکوس کردنش قالب را ضایع می‌کند.
- **`L` در نیروی برش محیط است، نه سطح.** خطای رایج: استفاده از `π·D²/4`.
- **`w` در نیروی خم طول خط خم است**، نه عرض ورق.
- **زاویه خم**: زاویه‌ی شامل (included) در برابر زاویه‌ی خم (bend angle) — مکمل یکدیگرند. در `BA` زاویه‌ی **خم** (چرخش) وارد می‌شود.
- **`E` بر حسب MPa** در فرمول برگشت فنری، نه GPa (ضریب ۱۰۰۰).

### محدوده اعتبار

- فرمول‌های نیرو تقریب‌های مهندسی با دقت **±۱۰–۲۰٪** هستند؛ برای انتخاب پرس مناسب‌اند، نه برای طراحی نهایی قالب.
- برگشت فنری با فرمول Kalpakjian برای خم خالص و ورق نازک معتبر است؛ برای فولاد پراستحکام و مقاطع پیچیده، خطا می‌تواند از ۵۰٪ بگذرد — شبیه‌سازی FEM لازم است.
- فرمول قطر بلانک فرض ضخامت ثابت دارد؛ برای کشش‌های عمیق با نازک‌شدگی زیاد، تصحیح لازم است.
- `F_hold` یک نقطه‌ی شروع است، نه جواب نهایی. مقدار بهینه از تست پرس یا شبیه‌سازی به دست می‌آید و اغلب در طول کورس **متغیر** است.
- نمودار حد شکل‌دهی (FLD) در این نسخه پوشش داده نشده — برای قطعات با کشیدگی دومحوره پیچیده لازم است.
