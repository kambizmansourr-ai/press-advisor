# فرم‌دهی حجمی — مرجع محاسبات مهندسی
# Bulk (Massive) Metal Forming — Engineering Calculation Reference

مرجع فرمول‌ها، ضرایب و مثال‌های حل‌شده برای افزودن ماژول «فرم‌دهی حجمی» به نرم‌افزار ماشین‌حساب مهندسی.
Companion to `bulkForming.js`. Every equation below maps to a named function in that module.

---

## 0. طبقه‌بندی — Classification

فرم‌دهی حجمی (bulk forming / Massivumformung) در برابر فرم‌دهی ورق (sheet forming) قرار می‌گیرد. معیار تفکیک: در فرم‌دهی حجمی نسبت سطح به حجم قطعه **کم** است و کرنش در تمام سه جهت اصلی قابل توجه است؛ ضخامت یک متغیر طراحی فعال است، نه یک قید ثابت.

| فرآیند | Process | تنش غالب | Dominant stress state |
|---|---|---|---|
| آهنگری | Forging | فشاری | Compressive |
| نوردکاری | Rolling | فشاری | Compressive |
| اکستروژن | Extrusion | فشاری | Compressive |
| کشش مفتول/میله | Wire / rod drawing | کششی + فشاری | Tensile + compressive |

چهار فرآیند بالا هسته‌ی استاندارد فرم‌دهی حجمی هستند و در این ماژول پوشش داده شده‌اند.

### دسته‌بندی دمایی — Temperature regimes

با `Tm` = دمای ذوب مطلق (K):

| رژیم | Regime | دما | اثر |
|---|---|---|---|
| سرد | Cold | `T < 0.3 Tm` | کارسختی شدید، دقت ابعادی بالا، نیروی زیاد |
| گرم | Warm | `0.3–0.5 Tm` | حد وسط، کاهش نیرو با حفظ دقت نسبی |
| داغ | Hot | `T > 0.5–0.6 Tm` | تبلور مجدد، نیروی کم، `n ≈ 0`، حساس به نرخ کرنش |

قاعده عملی: بالای دمای تبلور مجدد، توان کارسختی `n` عملاً صفر می‌شود و ماده به **نرخ کرنش** حساس می‌شود (`m` غالب).

## 1. مبانی مشترک — Common Fundamentals

این بخش پایه‌ی ورودی همه‌ی چهار فرآیند است. در نرم‌افزار بهتر است به‌عنوان یک «هسته» جدا پیاده شود و بقیه‌ی ماشین‌حساب‌ها آن را صدا بزنند.

### 1.1 ثبات حجم — Volume constancy

فرض بنیادی کل فرم‌دهی حجمی: تغییر شکل پلاستیک حجم را تغییر نمی‌دهد.

```
V0 = V1 = const
ε1 + ε2 + ε3 = 0            (کرنش حقیقی، true strain)
A0 · L0 = A1 · L1
```

برای استوانه در آهنگری آزاد: `d0² · h0 = d1² · h1`

این رابطه در نرم‌افزار باید به‌عنوان یک «حل‌کننده معکوس» هم عرضه شود: کاربر هر سه کمیت را بدهد، چهارمی محاسبه شود.

### 1.2 کرنش — Strain

```
کرنش مهندسی      e = (L1 − L0) / L0
کرنش حقیقی        ε = ln(L1 / L0)
تبدیل             ε = ln(1 + e)
```

در فرم‌دهی حجمی **همیشه** کرنش حقیقی به‌کار می‌رود؛ کرنش مهندسی برای کرنش‌های بزرگ (>0.1) خطای غیرقابل‌قبول می‌دهد.

- آهنگری آزاد (upsetting): `ε = ln(h0 / h1)`
- نورد: `ε = ln(t0 / t1)`
- اکستروژن/کشش: `ε = ln(A0 / Af)`

### 1.3 منحنی جریان — Flow curve

**سرد و گرم (Hollomon / Ludwik):**

```
σf = K · εⁿ
```

- `σf` = تنش جریان لحظه‌ای (MPa)
- `K` = ضریب استحکام (MPa)
- `n` = توان کارسختی (strain-hardening exponent)

**تنش جریان میانگین** — کمیتی که در محاسبه نیرو استفاده می‌شود (میانگین‌گیری روی مسیر کرنش از 0 تا ε):

```
Ȳf = K · εⁿ / (1 + n)
```

> ⚠️ نکته پیاده‌سازی: بیشتر خطاهای عددی در ماشین‌حساب‌های فرم‌دهی از جایگزینی اشتباه `σf` به‌جای `Ȳf` می‌آید. برای **نیرو** از `Ȳf` استفاده کنید، برای **بررسی تسلیم موضعی** از `σf`.

**داغ (نرخ‌کرنش‌حساس):**

```
σf = C · ε̇^m
```

- `C` = ضریب استحکام دمایی (MPa·s^m)
- `m` = توان حساسیت نرخ کرنش (0.05–0.4 برای فلزات داغ؛ >0.5 برای سوپرپلاستیک)
- `ε̇` = نرخ کرنش (1/s)

**فرم ترکیبی (توصیه‌شده برای گرم‌کار):**

```
σf = K · εⁿ · ε̇^m · exp(Q / (R·T))   ← فرم Zener–Hollomon، برای مدل‌های پیشرفته
```

### 1.4 نرخ کرنش — Strain rate

```
آهنگری:      ε̇ = v / h            (v = سرعت سنبه، h = ارتفاع لحظه‌ای)
نورد:        ε̇ = (v_r / L) · ln(t0/t1)
اکستروژن:    ε̇ = (6 · v_ram · D0² · tanα) / (D0³ − Df³)
کشش:         ε̇ = v_draw · ln(A0/Af) / Lc
```

توجه: در آهنگری، `ε̇` با کاهش `h` **افزایش** می‌یابد — پس در پرس هیدرولیک با سرعت ثابت، نرخ کرنش ثابت نیست.

### 1.5 معیار تسلیم و تنش جریان کرنش‌مسطح

**von Mises** (توصیه‌شده برای فلزات شکل‌پذیر):

```
σ̄ = (1/√2)·√[(σ1−σ2)² + (σ2−σ3)² + (σ3−σ1)²]
```

**Tresca** (محافظه‌کارانه، ساده‌تر):

```
σ̄ = σmax − σmin
```

**تنش جریان کرنش‌مسطح** (plane-strain flow stress) — برای نورد و آهنگری قطعات طویل:

```
Yf' = (2/√3) · Yf = 1.155 · Yf
```

این ضریب 1.155 در نورد و آهنگری تیغه‌ای/طویل باید اعمال شود؛ فراموش کردنش نیرو را ~15٪ کم‌برآورد می‌کند.

### 1.6 اصطکاک — Friction

**مدل Coulomb** (برای سرد‌کار با روانکار):

```
τ = μ · p          (تا سقف τ ≤ σ̄/√3)
```

**مدل تنش برشی ثابت / shear factor** (برای داغ‌کار، جایی که `p` بزرگ است):

```
τ = m · σ̄ / √3     ,   0 ≤ m ≤ 1
```

`m = 1` یعنی چسبیدن کامل (sticking). در داغ‌کار فولاد بدون روانکار `m ≈ 0.7–1.0`.

**جدول ضرایب اصطکاک — Friction coefficient table**

| شرایط | Condition | μ (Coulomb) | m (shear) |
|---|---|---|---|
| سردکار، روانکار خوب | Cold, good lubricant | 0.05–0.10 | 0.1–0.2 |
| سردکار، روانکار معمولی | Cold, moderate | 0.10–0.15 | 0.2–0.3 |
| گرم‌کار | Warm forming | 0.15–0.25 | 0.3–0.5 |
| داغ‌کار با روانکار (گرافیت/شیشه) | Hot, lubricated | 0.20–0.40 | 0.4–0.7 |
| داغ‌کار خشک | Hot, dry / sticking | 0.40–0.60 | 0.7–1.0 |
| نورد سرد فولاد | Cold rolling, steel | 0.05–0.10 | — |
| نورد داغ فولاد | Hot rolling, steel | 0.20–0.70 | — |
| کشش مفتول (صابون/روغن) | Wire drawing | 0.03–0.10 | — |
| اکستروژن سرد (فسفاته + روغن) | Cold extrusion | 0.05–0.10 | — |
| اکستروژن داغ آلومینیوم | Hot Al extrusion | 0.10–0.30 | — |

### 1.7 کار و انرژی تغییر شکل — Work and energy

**کار ایده‌آل واحد حجم** (ideal specific work):

```
u_ideal = ∫₀^ε σf dε = K·ε^(n+1)/(n+1) = Ȳf · ε
```

**کار کل:**

```
W_ideal = u_ideal · V
W_actual = W_ideal / η
```

**بازده تغییر شکل — Deformation efficiency η**

| فرآیند | Process | η |
|---|---|---|
| آهنگری آزاد | Open-die forging | 0.30–0.60 |
| آهنگری قالب بسته | Closed-die forging | 0.20–0.40 |
| نورد | Rolling | 0.70–0.90 |
| اکستروژن مستقیم | Direct extrusion | 0.50–0.65 |
| اکستروژن غیرمستقیم | Indirect extrusion | 0.60–0.75 |
| کشش مفتول | Wire drawing | 0.60–0.80 |

`1 − η` صرف اصطکاک و **کار زائد** (redundant work، تغییر شکل برشی داخلی بی‌اثر بر شکل نهایی) می‌شود.

**افزایش دمای آدیاباتیک** — مهم در اکستروژن و آهنگری سریع:

```
ΔT = (β · u_actual) / (ρ · cp)
```

`β ≈ 0.9` (سهم کار تبدیل‌شده به حرارت)، `ρ` چگالی (kg/m³)، `cp` گرمای ویژه (J/kg·K). در اکستروژن آلومینیوم این می‌تواند 100–250 °C باشد و عامل محدودکننده سرعت است.

### 1.8 توان — Power

```
P = F · v                     (فرآیند خطی: کشش، اکستروژن، آهنگری پرس)
P = 2π · N · T                (فرآیند دورانی: نورد)
```

با راندمان ماشین `η_m` (0.85–0.95 برای پرس‌ها، 0.85 برای قفسه نورد):

```
P_motor = P / η_m
```

## 2. آهنگری آزاد و فشردن — Open-Die Forging / Upsetting

### 2.1 هندسه

```
h1 = h0 − Δh                                (ارتفاع نهایی)
d1 = d0 · √(h0 / h1)                        (قطر نهایی از ثبات حجم)
A1 = π·d1²/4                                (سطح تماس لحظه‌ای)
ε  = ln(h0 / h1)
ε̇  = v / h1
```

### 2.2 تپه‌ی اصطکاک — The friction hill

فشار در سطح تماس یکنواخت **نیست**؛ از لبه به مرکز به‌صورت نمایی رشد می‌کند:

```
p(r) = Ȳf · exp[ 2μ(a − r) / h ]        (استوانه، a = شعاع، لغزش کامل)
p(x) = Yf' · exp[ 2μ(a − x) / h ]       (کرنش مسطح، تیغه با نیم‌عرض a)
```

نتیجه: با کاهش `h` (نسبت `d/h` بزرگ‌تر)، فشار مرکز شدیداً بالا می‌رود — دلیل اصلی این‌که آهنگری دیسک‌های نازک نیروی غیرمتناسب می‌خواهد.

### 2.3 نیرو — Force

**فرم Groover (توصیه‌شده به‌عنوان پیش‌فرض ماشین‌حساب):**

```
F = Kf · Ȳf · A1
Kf = 1 + 0.4 · μ · d1 / h1
```

**فرم Kalpakjian (میانگین‌گیری تحلیلی از تپه اصطکاک، خطی‌شده):**

```
p_avg = Ȳf · (1 + 2μ·a / (3h))  = Ȳf · (1 + μ·d1/(3·h1))
F = p_avg · A1
```

**فرم دقیق (انتگرال کامل تپه اصطکاک، استوانه):**

```
F = Ȳf · (2πh²/(4μ²)) · [ exp(2μa/h) − 2μa/h − 1 ]
```

**حالت چسبیدن کامل (sticking, μ ≥ 0.577):**

```
p_avg = Ȳf · (1 + 2a/(3√3·h))
```

**کرنش مسطح (تیغه‌ی طویل، عرض w، نیم‌عرض a):**

```
p_avg = 1.155 · Ȳf · (1 + μ·a/h)
F = p_avg · (2a · w)
```

> نکته: نیرو در آهنگری آزاد **در انتهای کورس حداکثر است** (هم `ε` بیشینه، هم `A` بیشینه، هم `d/h` بیشینه). ماشین‌حساب باید نیروی پایانی را به‌عنوان نیروی طراحی گزارش کند، نه نیروی میانگین.

### 2.4 انرژی و انتخاب ماشین

**پرس هیدرولیک** — انرژی از انتگرال نیرو:

```
W = ∫ F dh ≈ Ȳf · V · ε          (تقریب مهندسی)
W_actual = W / η
F_press ≥ 1.2 · F_max            (ضریب اطمینان توصیه‌شده)
```

**چکش سقوطی / Drop hammer** — انرژی ضربه:

```
E = ½ · m · v²  = m · g · H      (چکش سقوط آزاد از ارتفاع H)
E_available = E · η_blow          (η_blow ≈ 0.3–0.7)
تعداد ضربه لازم: N = W_actual / E_available
```

**پرس اصطکاکی/پیچی** — انرژی چرخ‌طیار:

```
E = ½ · I · ω²
```

### 2.5 بشکه‌ای شدن — Barreling

اصطکاک لبه‌ها را مقید می‌کند و مقطع بشکه‌ای می‌شود. شاخص عملی:

```
B = (d_max − d_end) / d_end
```

کاهش با: روانکاری بهتر، پیش‌گرم قالب، سنبه مقعر. هشدار نرم‌افزاری اگر `μ·d/h > 0.5`.

### 2.6 محدودیت‌های شکل‌پذیری

- **کمانش**: اگر `h0/d0 > 2` قطعه در فشردن کمانش می‌کند → قطعه را در چند مرحله فشرده کنید یا از قالب راهنما استفاده کنید.
- **ترک سطح آزاد**: تنش کششی محیطی در سطح بشکه‌ای؛ حد کرنش با نمودار FLD فشاری.

## 3. آهنگری قالب بسته — Closed-Die / Impression-Die Forging

### 3.1 نیرو

تحلیل دقیق میدان تنش در قالب بسته عملی نیست؛ روش استاندارد صنعتی **ضریب شکل** است:

```
F = Kf · Ȳf · A_projected
```

`A_projected` = سطح تصویرشده قطعه در صفحه عمود بر جهت حرکت قالب، **شامل پلیسه** (flash).

**جدول ضریب شکل Kf — Groover**

| نوع قطعه | Part type | Kf |
|---|---|---|
| ساده، بدون پلیسه | Simple, no flash | 3–5 |
| ساده، با پلیسه | Simple shapes with flash | 5–8 |
| پیچیده، با پلیسه | Complex shapes with flash | 8–12 |
| بسیار پیچیده، مقاطع نازک | Very complex, thin webs | 12–20 |
| سکه‌زنی | Coining | 12–20+ |

**فرم Siebel/Schuler (اروپایی، تفکیک بدنه و پلیسه):**

```
F = kf · [ A_body · (1 + 0.2·√(A_body)/s_avg) + A_flash · (1 + 1.26·b_f/s_f) ]
```

`b_f` = عرض زمین پلیسه، `s_f` = ضخامت پلیسه، `kf` = تنش جریان در دمای کار.

### 3.2 طراحی پلیسه — Flash design

پلیسه دو کار می‌کند: (1) مواد اضافی را خارج می‌کند، (2) با ایجاد مقاومت خروجی، **فشار پس‌زن** تولید می‌کند که حفره را پر می‌کند. پس ابعادش یک پارامتر طراحی حساس است.

قواعد عملی:

```
s_f (ضخامت پلیسه) ≈ 0.015 · √(A_projected)      [mm, A در mm²]
b_f / s_f = 2 تا 5                               (نسبت زمین به ضخامت)
V_flash ≈ (0.10 تا 0.30) · V_part               (10–30٪ حجم قطعه)
```

فشار پلیسه:  `p_flash ≈ kf · (1 + 1.26 · b_f/s_f)` — نازک‌تر و پهن‌تر ⇒ فشار بیشتر ⇒ پر شدن بهتر، اما نیرو و سایش قالب بیشتر.

### 3.3 محاسبه حجم بیلت — Billet volume

```
V_billet = V_part + V_flash + V_scale + V_sprue
V_scale ≈ (0.02 تا 0.05) · V_part      (پوسته اکسیدی، فقط داغ‌کار)
m_billet = ρ · V_billet
```

طول بیلت از میلگرد قطر `d`:  `L_billet = 4·V_billet / (π·d²)`

**بازده مواد:**  `η_mat = V_part / V_billet` (معمولاً 0.6–0.85 در آهنگری داغ)

### 3.4 شیب دیواره و شعاع‌ها — Draft and radii

| مورد | Item | فولاد | آلومینیوم |
|---|---|---|---|
| شیب خارجی | External draft | 3–5° | 1–3° |
| شیب داخلی | Internal draft | 5–7° | 2–5° |
| شعاع گوشه | Corner radius | ≥ 0.05·h | ≥ 0.05·h |
| شعاع فیله | Fillet radius | ≥ 0.10·h | ≥ 0.08·h |

شعاع کوچک ⇒ نیاز به فشار بیشتر برای پر شدن + تمرکز تنش در قالب. هشدار نرم‌افزاری اگر `R_fillet < 0.05·h`.

### 3.5 عمر قالب — Die life (تخمین تجربی)

```
N_die ≈ C_die / (p_avg^a · v_slide^b)
```

در عمل از داده تجربی استفاده می‌شود: فولاد داغ 5,000–20,000 قطعه؛ آلومینیوم داغ 20,000–100,000؛ سردکار فولاد 50,000–500,000.

## 4. نوردکاری تخت — Flat Rolling

### 4.1 هندسه

```
d = t0 − t1                          (کاهش ضخامت / draft)
r = d / t0                           (نسبت کاهش، reduction)
ε = ln(t0 / t1)
L = √(R · d)                         (طول قوس تماس، تقریب استاندارد)
α = arccos(1 − d/(2R))               (زاویه گاز/bite angle)
w1 = w0                              (فرض عدم پهن‌شدگی برای ورق عریض)
```

سرعت‌ها از ثبات حجم:  `t0·w0·v0 = t1·w1·v1`  ⇒ `v1 = v0 · t0/t1`

### 4.2 شرط گاز و حداکثر کاهش — Bite condition & max draft

قطعه فقط وقتی وارد قفسه می‌شود که مؤلفه اصطکاکی بر مؤلفه عمودی غلبه کند:

```
شرط گاز:      tan α ≤ μ        ⇒     α_max = arctan(μ)
حداکثر draft: d_max = μ² · R
```

این مهم‌ترین «هشدار» ماشین‌حساب نورد است: اگر کاربر `d > μ²R` وارد کند، فرآیند فیزیکاً ممکن نیست.

### 4.3 نیروی نورد — Roll force

**فرم پایه (Groover) — توصیه‌شده به‌عنوان پیش‌فرض:**

```
F = Ȳf · w · L                       (Ȳf = تنش جریان میانگین)
```

**با تصحیح کرنش‌مسطح (دقیق‌تر برای ورق عریض، w/t > 10):**

```
F = 1.155 · Ȳf · w · L
```

**فرم Ekelund (نورد داغ فولاد، شامل اصطکاک و نرخ کرنش):**

```
F = w · L · kf · (1 + (1.6μL − 1.2d)/(t0 + t1))
```

**فشار میانگین سطح تماس:**  `p_avg = F / (w · L)`

### 4.4 گشتاور و توان — Torque and power

```
T = 0.5 · F · L                      (به‌ازای هر غلتک، بازوی گشتاور ≈ L/2)
P = 2π · N · T                       (هر غلتک؛ N بر حسب rev/s)
P_total = 2 · 2π · N · T = 2π·N·F·L  (دو غلتک محرک)
```

مراقب یکا باشید: اگر `N` بر حسب rpm است، تقسیم بر 60 لازم است. این شایع‌ترین خطای واحد در ماشین‌حساب‌های نورد است.

### 4.5 نقطه خنثی و پیش‌لغزش — Neutral point & forward slip

پیش از نقطه خنثی قطعه کندتر از غلتک است، پس از آن تندتر.

```
پیش‌لغزش:    s = (v_exit − v_roll) / v_roll
موقعیت زاویه‌ای نقطه خنثی (تقریب):
φ_n = (α/2) · [1 − (α/(2μ))·... ]    ← از حل تعادل تپه اصطکاک
تقریب عملی:  φ_n ≈ α/2 · (1 − α/(2μ))
```

### 4.6 تخت‌شدگی غلتک — Roll flattening (Hitchcock)

غلتک زیر بار تغییر شکل الاستیک می‌دهد و شعاع مؤثر بزرگ‌تر می‌شود:

```
R' = R · [ 1 + (16(1−ν²)/(π·E)) · F/(w·d) ]
```

سپس `L` و `F` با `R'` بازمحاسبه می‌شوند — یک حلقه **تکراری** (iterative). در نورد سرد ورق نازک، نادیده‌گرفتنش نیرو را شدیداً کم‌برآورد می‌کند. در نرم‌افزار: 3–5 تکرار تا همگرایی 1٪.

### 4.7 اثر کشش — Effect of strip tension

اعمال کشش جلو/عقب نیروی نورد را کاهش می‌دهد (ابزار کلیدی نورد سرد):

```
F_with_tension ≈ (Ȳf − σ_t_avg) · w · L
σ_t_avg = (σ_back + σ_front) / 2
```

### 4.8 پهن‌شدگی — Spreading

برای مقاطع باریک (`w/t < 10`) عرض افزایش می‌یابد. تقریب Wusatowski:

```
w1/w0 = (t0/t1)^(10^(−1.269·(w0/t0)^0.556 · (t0/R)^0.294))
```

### 4.9 حداقل ضخامت قابل نورد — Minimum rollable thickness

```
t_min = (C · μ · R · Ȳf) / E
```

`C ≈ 6–8`. زیر این حد، غلتک‌ها روی هم تغییر شکل می‌دهند و ورق نازک‌تر نمی‌شود — دلیل استفاده از **نورد بسته‌ای** (pack rolling) و غلتک‌های کوچک با پشت‌بند.

## 5. اکستروژن — Extrusion

### 5.1 هندسه و کرنش

```
rx = A0 / Af                         (نسبت اکستروژن، extrusion ratio)
ε_ideal = ln(rx)
r = (A0 − Af)/A0                     (نسبت کاهش)
```

برای مقطع دایره: `rx = (D0/Df)²`

**کرنش واقعی (معادله Johnson)** — شامل کار زائد:

```
ε_x = a + b · ln(rx)
```

| ضریب | مقدار معمول | یادداشت |
|---|---|---|
| `a` | 0.8 | ثابت، سهم کار زائد پایه |
| `b` | 1.2 – 1.5 | تابع زاویه قالب؛ 1.2 برای قالب مخروطی بهینه، 1.5 برای قالب تخت (90°) |

### 5.2 فشار اکستروژن — Extrusion pressure

**اکستروژن غیرمستقیم (indirect / backward)** — بیلت ساکن، بی‌اصطکاک جداره:

```
p = Ȳf · ε_x
```

**اکستروژن مستقیم (direct / forward)** — اصطکاک جداره محفظه وارد می‌شود و با کوتاه‌شدن بیلت کاهش می‌یابد:

```
p = Ȳf · ( ε_x + 2L / D0 )
```

`L` = طول باقیمانده بیلت (لحظه‌ای). پس `p` در ابتدای کورس **حداکثر** است و به‌طور خطی می‌افتد — یک منحنی مشخصه که ماشین‌حساب باید ترسیم کند.

**نیرو:**  `F = p · A0`

**فرم ثابت اکستروژن (روش صنعتی سریع):**

```
F = A0 · Ke · ln(rx)
```

`Ke` = ثابت اکستروژن تجربی (MPa)، تابع ماده و دما — از جدول بخش 7.

### 5.3 زاویه قالب بهینه — Optimum die angle

دو اثر متضاد: زاویه کوچک ⇒ سطح تماس و اصطکاک بیشتر؛ زاویه بزرگ ⇒ کار زائد و منطقه مرده بیشتر.

```
α_opt ≈ arctan( √( (3/2) · μ · ln(rx) / ... ) )   ← فرم تحلیلی
عملی:  α_opt = 45° تا 60° (نیم‌زاویه) برای اکستروژن داغ
       α_opt = 20° تا 30° برای اکستروژن سرد
```

قالب تخت (90°) در اکستروژن داغ آلومینیوم رایج است چون **منطقه فلز مرده** خودش نقش قالب مخروطی را بازی می‌کند و اکسید سطحی را نگه می‌دارد.

### 5.4 نرخ کرنش و افزایش دما

```
ε̇ = (6 · v_ram · D0² · tanα) / (D0³ − Df³)
ΔT = β · p · ... / (ρ·cp)      ⇒  ΔT ≈ (0.9 · Ȳf · ε_x) / (ρ · cp)
```

**سرعت بحرانی**: اگر `T_billet + ΔT > T_solidus − 50°C`، ترک داغ (hot shortness) رخ می‌دهد. این قید سرعت خروج را در اکستروژن آلومینیوم تعیین می‌کند. ماشین‌حساب باید این هشدار را بدهد.

### 5.5 عیوب — Defects

| عیب | Defect | علت | کنترل |
|---|---|---|---|
| ترک سطحی | Surface cracking | سرعت/دما زیاد، ΔT بالا | کاهش سرعت یا دمای بیلت |
| لوله/قیف | Pipe / tailpipe defect | جریان اکسید سطحی به مرکز | دور ریختن 10–15٪ انتهای بیلت |
| ترک مرکزی | Center-burst / chevron | تنش کششی هیدرواستاتیک محوری | کاهش زاویه قالب، افزایش rx |

قید عملی: برای پرهیز از center-burst، `rx ≥ 2` و زاویه قالب متوسط.

## 6. کشش مفتول و میله — Wire and Rod Drawing

### 6.1 هندسه

```
r = (A0 − Af) / A0                   (نسبت کاهش)
ε = ln(A0 / Af)
D_avg = (D0 + Df) / 2
Lc = (D0 − Df) / (2 · sinα)          (طول تماس، α = نیم‌زاویه قالب)
```

### 6.2 تنش کشش — Draw stress

**ایده‌آل (بی‌اصطکاک، بی‌کار زائد):**

```
σd = Ȳf · ln(A0/Af)
```

**فرم Schey (توصیه‌شده — شامل اصطکاک و کار زائد):**

```
σd = Ȳf · φ · (1 + μ / tanα) · ln(A0 / Af)
```

که در آن **ضریب کار زائد** برای مقطع دایره:

```
φ = 0.88 + 0.12 · (D_avg / Lc)
```

**نیرو و توان:**

```
F = σd · Af
P = F · v_draw
```

### 6.3 حداکثر کاهش در هر پاس — Maximum reduction per pass

قید بنیادی: تنش کشش نمی‌تواند از تنش جریان ماده در خروج بیشتر شود، وگرنه مفتول **پاره** می‌شود.

```
شرط:  σd ≤ σf_exit
حد نظری (بی‌اصطکاک، بدون کارسختی):
   ln(A0/Af) ≤ 1  ⇒  r_max = 1 − 1/e = 0.632
عملی:  r = 0.20 – 0.30 (مفتول ریز)  ,  0.30 – 0.45 (میله)
```

با کارسختی (`n > 0`) حد نظری کمی بالاتر می‌رود؛ با اصطکاک پایین‌تر. ماشین‌حساب باید **حاشیه امنیت** `σd/σf_exit` را گزارش کند — هدف < 0.7.

### 6.4 چند پاس — Multi-pass schedule

برای رسیدن از `D0` به `Dn` در `N` پاس با کاهش یکنواخت:

```
r_pass = 1 − (Af/A0)^(1/N)
D_i = D0 · (Af/A0)^(i/(2N))
تعداد پاس لازم: N = ln(A0/Af) / ln(1/(1−r_pass))
```

بین پاس‌ها: آنیل میانی اگر کرنش تجمعی از ظرفیت شکل‌پذیری ماده عبور کند (فولاد کم‌کربن: `ε_total ≈ 2–4` قبل از آنیل).

### 6.5 زاویه قالب بهینه

```
α_opt ≈ √( (3/2) · μ · ln(A0/Af) )       [رادیان]
```

عملی: 6–10° نیم‌زاویه برای فولاد، 8–12° برای مس/آلومینیوم.

### 6.6 کشش عقب — Back tension

اعمال کشش عقب فشار قالب و سایش را کاهش می‌دهد، اما تنش کشش را بالا می‌برد:

```
σd_total = σd + σ_back
p_die = Ȳf − σ_back      ← فشار قالب کاهش می‌یابد
```

## 8. مثال‌های حل‌شده — Worked Examples

این مثال‌ها به‌عنوان **تست پذیرش** ماژول به‌کار می‌روند. مقادیر مورد انتظار در `bulkForming.test.js` نیز کدگذاری شده‌اند.

### مثال ۱ — آهنگری آزاد استوانه

قطعه استوانه‌ای فولاد 1010 سردکار: `d0 = 50 mm`, `h0 = 40 mm`, تا `h1 = 30 mm` فشرده می‌شود. `μ = 0.20`, `K = 530 MPa`, `n = 0.26`.

```
ε   = ln(40/30) = 0.2877
Ȳf  = 530 × 0.2877^0.26 / 1.26 = 530 × 0.7274 / 1.26 = 305.9 MPa
d1  = 50 × √(40/30) = 57.74 mm
A1  = π × 57.74²/4 = 2618.8 mm²
Kf  = 1 + 0.4 × 0.20 × 57.74/30 = 1 + 0.1540 = 1.154
F   = 1.154 × 305.9 × 2618.8 = 924,600 N ≈ 925 kN
V   = π×50²/4 × 40 = 78,540 mm³
W   = Ȳf·V·ε = 305.9 × 78,540 × 0.2877 = 6.91 kJ  (ایده‌آل)
W_actual (η=0.4) = 17.3 kJ
```

### مثال ۲ — نورد تخت

ورق فولادی، `t0 = 25 mm` → `t1 = 20 mm`, `w = 300 mm`, شعاع غلتک `R = 250 mm`, `N = 50 rpm`, `μ = 0.20`, `K = 530 MPa`, `n = 0.26`.

```
d       = 5 mm
r       = 0.20
d_max   = μ²R = 0.04 × 250 = 10 mm  ✓ (5 < 10، شدنی)
ε       = ln(25/20) = 0.2231
Ȳf      = 530 × 0.2231^0.26/1.26 = 530 × 0.6749/1.26 = 283.9 MPa
L       = √(250 × 5) = 35.36 mm
F       = 283.9 × 300 × 35.36 = 3,011,000 N ≈ 3011 kN
T       = 0.5 × 3011 × 0.03536 = 53.25 kN·m  (هر غلتک)
N       = 50/60 = 0.8333 rev/s
P_total = 2π × 0.8333 × 3,011,000 × 0.03536 = 557,300 W ≈ 557 kW
```

با تصحیح کرنش‌مسطح (×1.155): `F = 3477 kN`, `P = 644 kW`.

### مثال ۳ — اکستروژن مستقیم

بیلت آلومینیوم: `D0 = 100 mm`, `L = 300 mm` → `Df = 40 mm`. قالب مخروطی. `a = 0.8`, `b = 1.4`. تنش جریان میانگین داغ `Ȳf = 100 MPa`.

```
A0   = π×100²/4 = 7854 mm²
Af   = π×40²/4  = 1257 mm²
rx   = 6.25
ε_x  = 0.8 + 1.4 × ln(6.25) = 0.8 + 1.4 × 1.8326 = 3.366
p    = 100 × (3.366 + 2×300/100) = 100 × 9.366 = 936.6 MPa
F    = 936.6 × 7854 = 7,358,000 N ≈ 7358 kN
```

غیرمستقیم برای مقایسه: `p = 100 × 3.366 = 336.6 MPa`, `F = 2644 kN` — تفاوت ۲.۸ برابری، که چرا اکستروژن غیرمستقیم برای آلیاژهای سخت انتخاب می‌شود.

### مثال ۴ — کشش مفتول

مفتول فولادی `D0 = 3.0 mm` → `Df = 2.5 mm`، نیم‌زاویه قالب `α = 8°`, `μ = 0.07`, `K = 530 MPa`, `n = 0.26`، سرعت `2 m/s`.

```
A0    = 7.069 mm² ,  Af = 4.909 mm²
r     = 0.3056
ε     = ln(7.069/4.909) = 0.3646
Ȳf    = 530 × 0.3646^0.26/1.26 = 530 × 0.7710/1.26 = 324.3 MPa
D_avg = 2.75 mm
Lc    = (3.0−2.5)/(2×sin8°) = 0.5/(2×0.1392) = 1.796 mm
φ     = 0.88 + 0.12 × (2.75/1.796) = 0.88 + 0.1837 = 1.0637
σd    = 324.3 × 1.0637 × (1 + 0.07/tan8°) × 0.3646
      = 324.3 × 1.0637 × (1 + 0.4982) × 0.3646 = 188.4 MPa
F     = 188.4 × 4.909 = 925 N
P     = 925 × 2 = 1850 W
σf_exit = 530 × 0.3646^0.26 = 408.6 MPa
حاشیه: 188.4/408.6 = 0.46  ✓ (زیر 0.7، ایمن)
```

## 9. راهنمای پیاده‌سازی و اعتبارسنجی ورودی

### 9.1 هشدارهای الزامی — Required guards

ماشین‌حساب باید این بررسی‌ها را اجرا و به کاربر هشدار دهد:

| فرآیند | شرط | پیام |
|---|---|---|
| آهنگری | `h0/d0 > 2` | خطر کمانش — چند مرحله‌ای کنید |
| آهنگری | `μ·d1/h1 > 0.5` | بشکه‌ای شدن شدید و توزیع فشار غیریکنواخت |
| آهنگری | `μ ≥ 0.577` | حالت چسبیدن — از فرمول sticking استفاده شود |
| نورد | `d > μ²R` | گاز نمی‌کند (no bite) — کاهش draft یا افزایش μ |
| نورد | `t1 < t_min` | زیر حداقل ضخامت قابل نورد |
| اکستروژن | `rx < 2` | خطر center-burst |
| اکستروژن | `T + ΔT > T_solidus − 50` | ترک داغ — سرعت را کاهش دهید |
| کشش | `σd / σf_exit > 0.7` | خطر پارگی مفتول |
| کشش | `r > 0.45` | فراتر از حد عملی یک پاس |
| همه | `ε > 0` , `A > 0` , `0 < μ < 1` | ورودی نامعتبر |

### 9.2 یکاها — Units

توصیه: تمام محاسبات **داخلی** در SI پایه (m, N, Pa, s) انجام شود و تبدیل فقط در لایه ورودی/خروجی رخ دهد. اما چون داده مواد در MPa و ابعاد در mm است، سازگارترین انتخاب عملی:

```
طول: mm   |   سطح: mm²   |   تنش: MPa = N/mm²   |   نیرو: N
```

با این مجموعه، `MPa × mm² = N` بدون هیچ ضریب تبدیلی درست است. این «سیستم mm–N–MPa» است و کمترین منبع خطا را دارد. سپس فقط برای نمایش به kN/ton تبدیل کنید:

```
1 kN = 1000 N   |   1 tonf = 9806.65 N   |   1 kW = 1000 N·m/s
```

**تله‌های واحد شایع:**
- rpm در برابر rev/s در فرمول توان نورد (تقسیم بر 60)
- گشتاور: N·mm در برابر N·m (تقسیم بر 1000)
- زاویه: درجه در برابر رادیان در `tanα`, `sinα`
- چگالی: kg/m³ در برابر g/mm³ (ضریب 10⁶)

```
processes/
  forging.js         → upsetting, closedDie, flash, billetVolume

```

### 9.4 محدوده اعتبار فرمول‌ها — Validity limits

مهم است که کاربر بداند این‌ها **تقریب‌های مهندسی** هستند، نه شبیه‌سازی:

- روش تنش صفحه‌ای/slab: دقت ±10–20٪ برای هندسه ساده و متقارن.
- ضریب شکل `Kf` در قالب بسته: دقت ±25–40٪ — برای تخمین اولیه انتخاب پرس، نه طراحی نهایی قالب.
- معادله Johnson: تجربی، برای فلزات و محدوده‌های مرسوم اکستروژن؛ برای `rx > 100` یا مقاطع پیچیده نامعتبر.
- فرم Schey در کشش: معتبر برای مقطع دایره و `α < 15°`.
- تخت‌شدگی Hitchcock: فرض تماس الاستیک هرتزی؛ در نورد فویل به‌شدت غیرخطی می‌شود.
- برای طراحی نهایی، تحلیل اجزای محدود (FEM) با مدل مادی معتبر و آزمون اصطکاک واقعی (ring compression test) لازم است.
