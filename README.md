# سیستم هوشمند انتخاب پرس — ارس زنجان

سیستم پشتیبان تصمیم مهندسی که بر اساس کاربرد، جنس، و ابعاد قطعه مشتری، بهترین پرس را از میان محصولات
واقعی شرکت ارس زنجان (کاتالوگ رسمی AZCO) پیشنهاد می‌دهد — با استدلال مهندسی، فرمول‌های محاسبه نیرو،
و شفافیت کامل درباره کمبودهای اطلاعاتی منبع (صفحه «کیفیت داده»).

## اجرا برای توسعه

```bash
npm install
npm run dev
```

روی [http://localhost:3000](http://localhost:3000) باز می‌شود.

## ساخت نسخه آفلاین (PWA، بدون نیاز به سرور)

```bash
npm run build
npm start
```

`npm run build` یک خروجی کاملاً استاتیک در `out/` می‌سازد و سپس یک Service Worker
(`scripts/generate-sw.js`) تولید می‌کند که تمام فایل‌های اپلیکیشن را برای کارکرد آفلاین کش می‌کند.
`npm start` همان خروجی را با یک سرور استاتیک سبک (`scripts/serve.js`, بدون هیچ وابستگی npm) روی
`http://localhost:4173` اجرا می‌کند. از مرورگر می‌توانید با دکمه «نصب اپلیکیشن» آن را به‌صورت یک
اپلیکیشن مستقل با آیکون اختصاصی نصب کنید (Windows/Chrome/Edge).

روی ویندوز، فایل `اجرای-برنامه.bat` همین کار را با یک دوبار کلیک انجام می‌دهد.

## ساختار پروژه

```
src/
  types/         مدل‌های داده (Press, Application, Material)
  data/          پایگاه دانش: مدل‌های پرس، سری‌ها، مواد، کاربردها، کمبودهای داده
  calculators/   فرمول‌های مهندسی مستقل از UI (پانچ، خم، پرس‌فیت، پرچ، کوینینگ)
  rules/         موتور قوانین پیشنهاد پرس، مستقل از UI
  components/    کامپوننت‌های رابط کاربری
  app/           صفحات Next.js App Router
scripts/
  generate-sw.js  تولید Service Worker پس از build
  serve.js        سرور استاتیک آفلاین
  make-icons.js   تولید آیکون‌های PWA از لوگوی کاتالوگ
```

`Setak.pdf` استخراج شده است. جزئیات کمبودهای اطلاعاتی و مفروضات محاسباتی در صفحه `/data-quality`
اپلیکیشن مستند شده‌اند.
